# 한국어 연습 챗봇 (Korean Language Practice Chatbot)

Чат-бот на базе нейронных сетей для практики корейского языка.

## 📋 Описание проекта

Этот проект представляет собой Telegram-бота для практики корейского языка, использующего нейронные сети для генерации ответов. Бот обучен на датасете корейских диалогов и может поддерживать беседу на корейском языке.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка окружения

1. Скопируйте файл `.env.example` в `.env`:
```bash
copy .env.example .env
```

2. Откройте `.env` и добавьте токен вашего Telegram бота:
```
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
```

Токен можно получить у [@BotFather](https://t.me/BotFather) в Telegram.

### Обучение модели

Перед запуском бота необходимо обучить модель:

```bash
python src/train.py
```

Обучение может занять некоторое время в зависимости от размера датасета и мощности вашего компьютера.

### Запуск бота

После обучения модели запустите бота:

```bash
python src/bot.py
```

## 🔧 Основные компоненты

### `config.py`
Содержит все настройки проекта: пути к данным, параметры модели, настройки Telegram бота.

### `src/model.py`
Класс `KoreanChatbotModel` для работы с моделью нейронной сети. Использует трансформеры из библиотеки HuggingFace.

### `src/train.py`
Скрипт для обучения модели на датасете корейских диалогов.

### `src/bot.py`
Основной файл Telegram бота с обработчиками команд и сообщений.

### `src/utils.py`
Вспомогательные функции для загрузки и предобработки данных.

## 📚 Используемые библиотеки

- **pyTelegramBotAPI** - для работы с Telegram Bot API
- **transformers** - для работы с предобученными моделями трансформеров
- **torch** - фреймворк для глубокого обучения
- **datasets** - для работы с датасетами
- **pandas** - для обработки данных

## 🎯 Команды бота

- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/practice` - Начать режим практики
- `/stop` - Остановить режим практики

## ⚙️ Настройка модели

Параметры модели можно изменить в файле `config.py`:

```python
MODEL_CONFIG = {
    "model_name": "skt/kobert-base-v1",  # Модель из HuggingFace
    "max_length": 128,
    "batch_size": 16,
    "learning_rate": 2e-5,
    "num_epochs": 3,
    ...
}
```

## 📝 Примечания

- Для обучения модели рекомендуется использовать GPU (CUDA)
- Модель использует корейскую BERT модель `skt/kobert-base-v1`
- Датасет содержит более 11,000 пар вопрос-ответ на корейском языке

## 🔄 Разработка

Для добавления новых функций или улучшения модели:

1. Модифицируйте соответствующие файлы в `src/`
2. Обновите конфигурацию в `config.py` при необходимости
3. Переобучите модель командой `python src/train.py`
4. Перезапустите бота
